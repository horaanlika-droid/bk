# Большой Кофе — web app / Telegram Mini App

Минималистичное приложение кофейни на русском языке: меню, корзина, заказ с собой или заказ уже из кофейни, бонусная механика-прототип и уведомления администраторам в Telegram. Адаптируется под узкий экран, планшет и десктоп. Открывается как обычный сайт и поддерживает Telegram Web App SDK, если запущено из бота.

## Запуск

Требуется Node.js 18+ (встроенный `fetch`). Сторонние npm-пакеты не нужны.

```sh
cp .env.example .env # опционально; переменные нужно экспортировать в окружение процесса
BOT_TOKEN=... ADMIN_IDS=123456789,987654321 npm start
```

Откройте `http://localhost:3000`. Для реального запуска задайте `BOT_TOKEN` и `ADMIN_IDS` в настройках хостинга. `ADMIN_IDS` — числовые Telegram ID администраторов через запятую. Бот шлёт им новые заказы; команда `/orders` показывает последние заказы. Данные заказов хранятся в `data/orders.json` (каталог создаётся автоматически, файл не следует публиковать). Без токена приложение работает как сайт, но не отправляет уведомления.

## Telegram Mini App

Создайте бота через @BotFather, установите ему Menu Button / Web App URL на HTTPS-адрес приложения и добавьте администраторов в `ADMIN_IDS`. Пользователи могут оформить заказ без Telegram: имя и телефон вводятся при оформлении. Telegram ID используется как дополнительная справочная информация, не как обязательный способ авторизации.

## Что пока прототип

- Оплата при получении; API ЮKassa не подключено, секреты платежей не требуются.
- Меню и цены собраны по изображениям меню из репозитория. Категории, цены и адреса конкретных точек перед запуском стоит сверить с кофейней: исходные материалы не содержат машиночитаемого актуального каталога или списка адресов. В интерфейсе пока выбор города «Волжский / Волгоград», без выбора конкретного адреса.
- Начисление — 5% от суммы, 1 БК-Коин = 1 ₽. Пока баланс прототипа хранится в localStorage браузера: он не синхронизируется между устройствами и не является защищённым от изменения. Для настоящей программы лояльности нужен постоянный серверный профиль и идентификация клиента.
- Администраторы получают уведомление и список заказов в боте; смена статуса заказа и ответы клиенту пока не реализованы.
- Нет корзинной оплаты бонусами, расписания предзаказа, статусов приготовления и подтверждения телефона. Заказ отправляется сразу в API.

## Переменные окружения

См. `.env.example`: `BOT_TOKEN`, `ADMIN_IDS` и опциональный `PORT` (по умолчанию 3000). Для ЮKassa позже можно будет добавить отдельные серверные параметры, не выставляя секреты в браузер.
